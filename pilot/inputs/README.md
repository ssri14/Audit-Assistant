# Fictional workshop packet

Procurement_Dossier.pdf is a four-page native-text target. Procurement_Dossier_Mixed.pdf contains the same records with page 3 rasterized to exercise the vision model. Procurement_Procedure.pdf and Payment_Checklist.pdf are reference books, totaling three pages. All transactions, thresholds and rules are fictional training material created for this project, not legal or government guidance.

The app's demo button loads the mixed target and both references. The native target is also included for PDF highlighting checks. Evaluation answers and recorded model responses are not bundled. Run prepare_pilot.py (requires reportlab in addition to app dependencies) to regenerate this packet.
